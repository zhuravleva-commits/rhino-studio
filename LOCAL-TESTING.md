# Локальное тестирование Rhino Studio

Эта папка содержит отдельную копию проекта из `rhino-studio-main.zip`.

## Запуск

Откройте `start-local.cmd` двойным щелчком или выполните в этой папке:

```powershell
npm.cmd run dev -- --hostname 127.0.0.1 --port 3000
```

Адрес сайта: http://127.0.0.1:3000

Изменения исходников автоматически обновляются в браузере. Для остановки нажмите Ctrl+C в окне сервера. Перед повторным запуском остановите уже работающий экземпляр.

## Сборка

```powershell
npm.cmd run build
```

Результат сборки сохраняется в `dist`.

Для переустановки зависимостей: `npm.cmd ci`. Требуется Node.js версии 22.13 или новее.
